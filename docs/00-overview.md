# 00. 개요

## 1. 목표
- 라즈베리파이 5에서 셀프호스팅 서비스를 Docker Compose로 운영한다.
- **포털 웹앱**을 직접 개발해 서비스 런처, 상태 모니터링, Docker 제어, 시스템 지표, 알림, 감사 로그를 한 곳에서 제공한다.
- 접속 경로는 두 가지다. **내부(Tailnet)**: Tailscale로 접속. **외부(공개)**: Tailscale Funnel이 제공하는 공개 주소로 접속.
- 개발은 Codex 에이전트 오케스트레이션(혼합형: 페이즈 순차 + 페이즈 내 병렬)으로 진행한다.

## 2. 확정된 결정

| 항목 | 결정 |
|---|---|
| 포털 방식 | 직접 개발 |
| 백엔드 | Spring Boot 3.x (Java 21), Gradle |
| 프론트엔드 | React + TypeScript + Vite |
| 오케스트레이션 | 혼합 (페이즈 순차, 페이즈 내 병렬) |
| 접속 | Tailscale (내부) + Tailscale Funnel (외부 공개) |
| 서비스 | 기성품 Docker 이미지 (직접 구현하지 않음) |

세부 기술 결정은 `docs/adr/`에, 미결 사항은 `docs/09-open-questions.md`에 있다.

## 3. 범위

### In scope
1. 인프라: Docker, Compose, 리버스 프록시, Tailscale Serve/Funnel, 소켓 프록시, 백업.
2. 기성 서비스: Vaultwarden, Uptime Kuma (필수) → Pi-hole, Nextcloud 등 (선택, 후순위).
3. 포털 백엔드: 인증(+2FA), 서비스 레지스트리, 헬스체크, Docker 제어, 시스템 지표, 알림, 감사 로그.
4. 포털 프론트엔드: 로그인, 대시보드(런처+상태), 컨테이너 관리, 시스템 지표, 알림 설정, 감사 로그.

### Out of scope (초기)
- 다중 사용자/권한 체계 (단일 관리자 + 선택적 읽기 전용 계정까지만)
- 쿠버네티스, 다중 노드
- 기성 서비스 내부 기능 개발

## 4. 환경 (현재 확인된 사실)

| 항목 | 값 |
|---|---|
| 하드웨어 | Raspberry Pi 5 |
| OS | Debian 13 (trixie), arm64, 커널 6.18 |
| RAM | 8GB |
| 저장소 | **SD카드 57GB만 존재** (SSD 없음) |
| 설치 상태 | Docker, Java, Tailscale **미설치** / Node 설치됨 |

### 환경에서 오는 제약
1. **SD카드 단독 운영 (SSD 도입 안 함, Q1 확정)**: 쓰기 수명과 고장 위험을 설계 전제로 삼는다. 쓰기 최소화 정책(`docs/02` §11)과 **외부 백업**을 필수로 하고, 쓰기·용량이 큰 서비스(Immich, Nextcloud 대용량, Jellyfin 라이브러리 등)는 범위에서 제외하거나 후순위로 둔다.
2. **JVM 메모리**: Spring Boot는 Node/Python보다 무겁다. 컨테이너 메모리 한도와 `-Xmx`를 명시한다 (`docs/02` §자원 예산).
3. **arm64**: 모든 이미지는 `linux/arm64`를 지원해야 한다.
4. **빌드 위치**: Pi에서 Gradle/Vite 빌드는 느리다. 가능하면 개발 머신/CI에서 arm64 이미지를 빌드해 푸시하고 Pi는 pull만 한다 (`docs/02` §빌드·배포).

## 5. 성공 기준
- [ ] Tailnet 내 기기에서 포털에 로그인해 모든 서비스 상태를 볼 수 있다.
- [ ] 공개 주소로 접속하면 포털 로그인(+2FA)만 노출되고, 내부 서비스는 노출되지 않는다.
- [ ] 포털에서 허용된 컨테이너를 재시작/중지/시작할 수 있고, 모든 조작이 감사 로그에 남는다.
- [ ] 서비스 다운 시 5분 이내 알림이 간다.
- [ ] 백업에서 복구하는 드릴을 1회 이상 성공한다 (SD카드 교체 시나리오 포함).
- [ ] 전체 스택 유휴 시 메모리 사용이 예산 이내다.

## 6. 용어
- **Tailnet**: Tailscale 사설 네트워크. **Serve**: tailnet 내부 공개. **Funnel**: 인터넷 공개.
- **Managed Service**: 포털이 레지스트리에 등록해 관리하는 서비스(컨테이너 또는 URL).
- **Socket Proxy**: Docker API를 허용된 엔드포인트만 통과시키는 프록시 컨테이너.
