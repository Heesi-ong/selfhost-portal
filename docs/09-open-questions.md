## 기술 리스크

| 리스크 | 완화 |
|---|---|
| Spring Boot 메모리가 예산(384MB)을 초과 | `-Xmx256m`, SerialGC, 스타터 최소화, 측정 후 조정. 필요 시 GraalVM native 또는 Quarkus 검토(ADR) |
| SQLite + SD카드 쓰기 마모 | `docs/02` §11 쓰기 최소화 정책(배치 쓰기, 짧은 보존, tmpfs 로그), 외부 백업 필수, SD카드 교체 절차를 런북에 포함 |
| SD카드 고장으로 전체 유실 | 일 1회 외부 백업 + 월 1회 복구 드릴, 부팅 SD 이미지 백업 |
| Funnel 대역폭/포트 제한 | 포털 1개만 공개, 정적 자산 캐시 |
| Funnel 경유 시 클라이언트 IP 식별 | `X-Forwarded-For` 신뢰 프록시 설정 및 테스트 |
| 소켓 프록시 `POST=1` 시 쓰기 권한 | 백엔드 allowlist 이중 강제, 감사 로그 |
| docker-java 의존성 크기/호환 | 필요 시 JDK HttpClient로 Docker REST 직접 호출 대체 (ADR) |
