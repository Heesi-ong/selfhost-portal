# T-011 Compose 골격 + 소켓 프록시 + Caddy
- 담당: Infra
- 페이즈: 1
- 선행: T-010
- 병렬 가능: T-013, T-014

## 목표
핵심 스택의 Compose 골격을 만들고 Caddy private/public 블록과 Docker 소켓 프록시를 구성한다. 포털은 아직 자리표시자(placeholder)로 둔다.

## 입력 문서
- AGENTS.md
- docs/01-architecture.md §1~2
- docs/02-infrastructure.md §3~4, §6
- docs/06-security.md §2, §5, §6

## 범위
- In:
  - `infra/compose/compose.yaml`: caddy, docker-socket-proxy, portal-api(placeholder 이미지 또는 주석 처리된 서비스), 네트워크 `edge`/`backend(internal)`
  - 이미지 **버전 고정**, `mem_limit`, `logging`, `restart`, `healthcheck`, `read_only` + tmpfs, `cap_drop: [ALL]`, `no-new-privileges`
  - socket-proxy: 기본 deny, `CONTAINERS=1 INFO=1 EVENTS=1 POST=1`, 나머지 0 (`docs/02` §3.1)
  - `infra/caddy/Caddyfile`: private `127.0.0.1:8080`, public `127.0.0.1:8081` (포털 SPA + `/api/**`만, 그 외 404), 보안 헤더(CSP 포함), `X-Portal-Origin` 덮어쓰기, `/api/v1/stream`용 `flush_interval -1`, `trusted_proxies`
  - `.env.example`
- Out: Tailscale(T-012), Vaultwarden/Kuma(T-015), 실제 포털 이미지(T-025)

## 산출물
- `infra/compose/compose.yaml`, `compose.dev.yaml`, `.env.example`, `infra/caddy/Caddyfile`

## 완료 기준 (DoD)
- [ ] `docker compose config` 유효, `latest` 태그 없음
- [ ] `curl -sI 127.0.0.1:8081/` 응답 헤더에 보안 헤더 존재, `/admin` 등 임의 경로는 404
- [ ] private 블록과 public 블록의 `X-Portal-Origin` 값이 다름을 `curl`로 증빙 (클라이언트가 보낸 값은 무시됨)
- [ ] 호스트에 publish된 포트는 `127.0.0.1:8080/8081`뿐 (`docker ps`, `ss -tlnp` 첨부)
- [ ] socket-proxy가 허용되지 않은 API(`/images`, `/exec`)에 403 응답
- [ ] `check-resources.sh` 결과가 예산 이내
