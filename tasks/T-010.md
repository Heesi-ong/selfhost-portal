# T-010 호스트 준비 스크립트 (SD 쓰기 최소화 포함)
- 담당: Infra
- 페이즈: 1
- 선행: T-002 (Q1~Q5 결정 반영 완료)
- 병렬 가능: T-013, T-014

## 목표
Pi 호스트를 Docker 운영 가능 상태로 만드는 **멱등** 스크립트를 작성한다. SD카드 단독 운영 정책(`docs/02` §11)을 적용한다.

## 입력 문서
- AGENTS.md
- docs/02-infrastructure.md §1, §11
- docs/06-security.md §8
- docs/adr/README.md (ADR-0008)

## 범위
- In:
  - `infra/scripts/bootstrap.sh`: Docker Engine + Compose plugin(공식 apt 저장소, arm64), `/etc/docker/daemon.json`(json-file 10m×3), `/srv/selfhost/*` 생성, `ufw`(기본 deny incoming, SSH는 LAN/tailnet 한정), `unattended-upgrades`
  - SD 쓰기 최소화: `/etc/fstab` noatime 제안(자동 수정 대신 **diff 출력 후 확인 프롬프트**), `journald` `Storage=volatile` drop-in, 디스크 스왑 비활성(zram 유지)
  - `infra/scripts/check-resources.sh`: 메모리, 디스크 사용률, **일일 쓰기량(MB/day, `/sys/block/mmcblk0/stat`)**, 온도, 컨테이너별 mem 출력
  - `--dry-run` 옵션 (변경 없이 수행 계획 출력)
- Out: Tailscale 설치(T-012), compose 스택(T-011)

## 산출물
- `infra/scripts/bootstrap.sh`, `infra/scripts/check-resources.sh`, `infra/README.md`(실행법)

## 완료 기준 (DoD)
- [ ] `shellcheck` 경고 없음
- [ ] `bootstrap.sh --dry-run` 출력이 사람이 검토 가능
- [ ] 2회 연속 실행해도 결과 동일 (멱등) — 두 번째 실행 로그 첨부
- [ ] `docker run --rm hello-world` 성공 (arm64)
- [ ] `docker` 그룹에 사용자 추가하지 않음 (`docs/02` §1)
- [ ] `check-resources.sh` 샘플 출력 첨부
- [ ] 비밀/개인정보 없음

## 수동 단계 🙋
- `sudo`가 필요한 `bootstrap.sh` 실행 (사용자가 `! sudo infra/scripts/bootstrap.sh`로 실행)
- fstab 변경 승인
