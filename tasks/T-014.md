# T-014 프론트엔드 프로젝트 골격
- 담당: Frontend
- 페이즈: 1
- 선행: T-003 (OpenAPI 1차 확정)
- 병렬 가능: T-011, T-012, T-013

## 목표
React+TS+Vite 골격과 openapi 타입 생성 파이프라인, MSW Mock, 라우팅/레이아웃을 만든다. 백엔드 없이 Mock으로 개발·테스트 가능해야 한다.

## 입력 문서
- AGENTS.md
- docs/04-frontend-spec.md 전체
- docs/06-security.md §3~4 (쿠키/CSRF/CSP)
- api/openapi.yaml

## 범위
- In:
  - Vite + React 18 + TypeScript(strict), React Router, TanStack Query
  - `npm run gen:api`: `openapi-typescript`로 `../api/openapi.yaml` → `src/api/schema.d.ts`, fetch 래퍼(CSRF 헤더 `X-XSRF-TOKEN`, `credentials: 'include'`, Problem Details 파싱)
  - MSW 핸들러 (openapi 예시 기반): `/health`, `/auth/login`, `/auth/me`, `/services`
  - 라우트 골격: `/login`, `/`, `/services`, `/containers`, `/metrics`, `/alerts`, `/audit`, `/settings` (본문은 빈 화면 + 로딩/빈/오류 상태 컴포넌트)
  - 레이아웃(반응형, 360px), 다크/라이트, `StatusBadge`(색+아이콘+텍스트)
  - 스타일 도구: Tailwind(Q11 기본값)
  - ESLint, Prettier, Vitest + Testing Library, 번들 크기 측정 스크립트
- Out: 실제 화면 기능(T-023, T-024 등), 인증 로직
